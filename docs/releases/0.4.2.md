# Span 0.4.2

Find familiar faces at Lenny & Friends and explore a searchable desktop attendee directory.

Download **Span-macOS.dmg**, open it, and drag Span to Applications. The “Source code” archives are for developers. Requires macOS 13 or later on an Apple-silicon Mac, access to the event app, and a LinkedIn connections export for matching. [Setup guide](https://github.com/jmania/span/blob/main/docs/getting-started.md)

## Included

- Automatic first-degree matching from your own export.
- Searchable directory with LinkedIn searches and optional manual labels.
- Collection that returns to the beginning, reads all visible rows, and verifies the event app’s total.
- Saved inputs, cancellation, and rescanning without reimporting the archive.

## Verification and limits

The development build completed a live scan of all 1,355 attendees on September 7, 2026, starting from the bottom. Automated checks cover traversal, matching, input order, and persistence. The signed installer still requires a separate pilot installation check before this draft is published.

Span reads list cards, not every profile-detail page. Second-degree labels are manual. Name matches can be ambiguous.
