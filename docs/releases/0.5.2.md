# Span 0.5.2 — Easier setup and feedback

Two small usability updates:

- When the event app is not installed, Span’s setup screen links directly to [Lenny & Friends Summit on the App Store](https://apps.apple.com/us/app/lenny-friends-summit/id6800677901). The GitHub installation instructions include the same link.
- Span’s footer and GitHub instructions now invite you to [comment on Josh’s LinkedIn post](https://www.linkedin.com/feed/update/urn:li:activity:7502873550244966400/) if you need help or have feedback.

No changes to attendee collection, identity matching, saved data, or profile-detail collection. Existing users can quit Span, download the new installer, and replace the app in Applications; saved inputs and decisions are retained.

Requires macOS 13+, an Apple-silicon Mac (M1 or newer), and access to the event app. The LinkedIn export is optional for browsing. Free, MIT-licensed, independent and unofficial; not affiliated with the summit or LinkedIn. Software and results are provided as-is.
