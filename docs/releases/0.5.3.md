# Span 0.5.3 — Keep complete attendee scans

Span now keeps a completed scan when it reads more attendees than the event app’s displayed count, instead of discarding the collection. Scans that read fewer attendees than advertised still report an incomplete scan.

## Thank you, Andrew! 🎉

Huge thanks to @andrewdraper for Span’s first community contribution, [PR #5](https://github.com/jmania/span/pull/5)! Andrew supplied a focused fix, a clear explanation, and a regression test to keep this bug from coming back. We’re delighted to have your help making Span better.

This is a focused bug-fix release. It does not include the unfinished profile-enrichment work or changes to identity matching.

To update, quit Span, download the new installer, and replace the app in Applications. Saved inputs and decisions are retained.

Requires macOS 13+, an Apple-silicon Mac (M1 or newer), and access to the event app. The LinkedIn export is optional for browsing. Free, MIT-licensed, independent and unofficial; not affiliated with the summit or LinkedIn. Software and results are provided as-is.
