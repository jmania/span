# Contributing to Span

Use, modify, and redistribute the code under the [MIT license](LICENSE); retain its copyright and permission notice. Thanks for helping make Span useful.

Useful improvements include name matching, accessible onboarding, resilient collection, and support for other event apps.

1. Fork the repository and create a branch.
2. Follow [the development guide](docs/development.md).
3. Keep changes focused and explain the user problem in your pull request.
4. Run checks relevant to your change. Add a regression test when fixing matching or collection behavior.

Use fictional fixtures. Do not commit attendee lists, LinkedIn exports, cookies, credentials, or private contact data. Please keep processing local and avoid adding automated LinkedIn scraping or bulk outreach.

Open an issue before a larger change so we can discuss its fit. Bug reports and documentation improvements are welcome too.
